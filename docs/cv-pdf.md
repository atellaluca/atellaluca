- Runtime contract enforcement engine for Python modules
- YAML-based declarative contracts for structural, contextual, and execution constraints

- Uses GDAL, Rasterio, NumPy, PyVista, Fiona, and Typer
- Separates raw data, processed datasets, build artifacts, and model outputs for reproducible data-to-model processing
