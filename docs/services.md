## How I can help

<div class="portfolio-card-grid" markdown>
<div class="portfolio-card" markdown>
<p class="portfolio-eyebrow">01 · INFRASTRUCTURE & DATA</p>

### Servers, networks and private cloud

Business files and services should be available to authorized users and recoverable when something fails. I design and modernize Linux and Windows infrastructure, controlled remote access and storage sized for the actual workload.

- Local servers, centralized file storage (NAS) and isolated environments for services
- File access and collaboration, including self-hosted tools where appropriate
- Private VPNs, permissions and network access boundaries
- Multiple backup copies, restore verification and recovery planning

<p class="portfolio-stack">Debian · Docker · NAS · VPN · Storage · Nextcloud where appropriate</p>
</div>
<div class="portfolio-card" markdown>
<p class="portfolio-eyebrow">02 · SUPPORT & OPTIMIZATION</p>

### Diagnose issues and improve daily work

Slow computers, legacy applications and untested backups can interrupt daily work. I diagnose the issue, improve equipment worth keeping, and help establish predictable operations.

- Hardware and software diagnosis, upgrades and computer refurbishment
- Migration and consolidation of workstations, systems and data
- Application compatibility, including software that needs different versions of Java
- Monitoring, preventive maintenance and operational documentation

<p class="portfolio-stack">Windows · Linux · Checkmk · Backups · Troubleshooting</p>

[Example: tax software and isolated Java runtimes →](case-studies/agenzia-entrate-runtime-isolation/index.md)
</div>
<div class="portfolio-card" markdown>
<p class="portfolio-eyebrow">03 · SOFTWARE & INTEGRATIONS</p>

### Make existing systems work together

When applications cannot exchange information, or teams repeatedly copy data by hand, I build dedicated software, backend services and integrations that fit the workflow.

- Dedicated applications, backend services and connections between applications (APIs)
- Automation of repetitive operational processes
- Ingestion and transformation of data from heterogeneous sources
- Modular architecture, modernization and ongoing improvements
- Deployment, tests, logging and technical documentation

<p class="portfolio-stack">Python · FastAPI · REST APIs · Docker · AWS</p>

[Example: cloud-portable fleet platform →](case-studies/cloud-portable-fleet-platform/index.md)
</div>
<div class="portfolio-card" markdown>
<p class="portfolio-eyebrow">04 · AI & AUTOMATION</p>

### Reduce repetitive work, responsibly

I evaluate whether conventional automation or AI could help classify, extract, organize or retrieve information, taking the business data involved into account. Work starts with a feasibility assessment and a prototype to check benefits and limitations.

- Workflow review and practical feasibility assessment
- Prototypes and integrations with business tools
- Hardware, running costs and data requirements for local models or external services
- Real-world testing, human oversight and measurable outcomes

<p class="portfolio-stack">Python · Workflows · LLMs · Local AI where feasible</p>
